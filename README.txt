# Console StudyHub Planner
## Возможности: добавление, просмотр, поиск, завершение задачи и статистика.
## Запуск с командами python main.py и py main.py.
## Проверка: добавить две задачи, завершить одну, вывести статистику.

## Контрольный сценарий.
Шаг 1. Запустите проект командой из README.

Шаг 2. При пустом списке вызовите просмотр: должно появиться понятное сообщение без traceback.

Шаг 3. Добавьте Повторить Python с приоритетом 4 и Сделать README с приоритетом 2.

Шаг 4. Выведите список и проверьте разные стабильные id.

Шаг 5. Найдите Сделать README по id или поддерживаемому поиску.

Шаг 6. Отметьте Повторить Python выполненной и снова покажите список.

Шаг 7. Покажите статистику: одна задача выполнена, одна открыта.

Шаг 8. Введите неизвестную команду и пустое название. Программа должна сообщить об ошибке и продолжить работу.

Шаг 9. Завершите программу штатной командой.
